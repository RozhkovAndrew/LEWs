# Learning English Words (LEWs)

Простое web-приложение для изучения английского языка (хотя можно учить любые определения). Включает себя схему базу данных (SQLite) и интерфейс для работы с ней, включающий в себя словарь, инструменты корректировки словря и модуль проверки знания для формирования заданий и проверки ваших ответов.
Для примеры добавил в репозиторий тестовую базу данных app.db.
Чтобы ознакомиться с проектом можно перейти по ссылке https://a93pav.pythonanywhere.com .
Сейчас работаю над адаптацией мобильной версии.

## Установка и запуск

```bash
git clone https://github.com/RozhkovAndrew/LEWs
cd LEWs
pip install -r requirements.txt
python main.py
```

## Технологии
  •	Python 3.12
  •	Flask
  •	SQLAlchemy
  • Bootstrap
