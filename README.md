# Название проекта

Простое web-приложение для изучения английского языка (хотя можно учить любые определения). Включает себя базу данных (SQLite) и интерфейс для работы с ней, а также модуль проверки знания для формирования зданий и проверки ваших ответов.
Для примеры добавил в репозиторий тестовую базу данных app.db.
Чтобы ознакомиться с проектом можно перейти по ссылке (в работе).

## Установка и запуск

```bash
git clone https://github.com/RozhkovAndrew/LEWs
cd LEWs
pip install -r requirements.txt
python main.py
